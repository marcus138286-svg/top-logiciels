# Structure des images

## /logos/
Logos officiels des outils (format: nom-outil.webp ou .png)
- getresponse.webp
- brevo.webp
- hubspot.webp
- etc.

Taille recommandée: 200x200px ou 400x200px (logo horizontal)

## /screenshots/
Captures d'écran des interfaces
- getresponse-dashboard.webp
- hubspot-pipeline.webp
- etc.

Taille recommandée: 1200x675px (ratio 16:9)

## /blog/
Images pour les articles de blog
- freelance-stack.webp
- crm-comparison.webp
- etc.

Taille recommandée: 1200x630px

## /og/
Images Open Graph pour le partage social
- home.png
- comparatif-crm.png
- etc.

Taille obligatoire: 1200x630px

## Conseils
- Utiliser le format WebP quand possible (plus léger)
- Compresser avec squoosh.app ou tinypng.com
- Nommer en minuscules avec tirets (hubspot-crm.webp)
